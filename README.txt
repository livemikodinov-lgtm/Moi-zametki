МОИ ЗАМЕТКИ — пробная версия

Что есть:
- темы с названием, значком, цветом карточки и цветом текста;
- подтемы и пункты внутри подтем;
- цвет текста каждого пункта;
- временные заметки, которые истекают через 24 часа после создания;
- локальное сохранение в браузере;
- экспорт и импорт резервной копии JSON;
- базовый офлайн-кеш после первого открытия.

ВАЖНО:
1. Это первая пробная версия, не опубликованная в магазине приложений.
2. Для установки как приложения с иконкой на Android её нужно разместить на HTTPS-хостинге (например, GitHub Pages), затем открыть ссылку в Chrome и выбрать меню браузера → «Добавить на главный экран» / «Установить приложение».
3. Заметки хранятся в браузерном хранилище на устройстве. Очистка данных сайта/браузера может их удалить. Делайте экспорт резервной копии регулярно.
4. Автоочистка временных записей происходит при открытии приложения/обновлении списка. Если приложение закрыто, запись может физически оставаться в хранилище до следующего запуска, но она будет скрыта и удалена при следующем открытии.
5. Не используйте как единственное хранилище критически важных данных без резервных копий.
