МОИ ЗАМЕТКИ — версия с фотографиями

Возможности: темы, подтемы, пункты, настройка цветов, временные заметки с очисткой через 24 часа, локальное хранение, экспорт/импорт JSON.

Обновление: в GitHub откройте index.html, нажмите карандаш Edit, замените код файлом index.html из этого архива (удобнее с компьютера, либо через мобильный редактор, если он позволяет загрузить/заменить файл), затем Commit changes. Файлы manifest.json, sw.js и icon.svg также можно обновить.

Фотографии вставляются прямо внутрь текста заметки. Перед сохранением изображения автоматически уменьшаются и сжимаются. Данные остаются в локальном хранилище браузера; делайте резервные копии через настройки. Очистка данных сайта может удалить заметки.
